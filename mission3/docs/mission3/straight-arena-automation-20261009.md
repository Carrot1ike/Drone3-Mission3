# 직선 경기장과 미션3 실행 프로그램

2026-10-09 사용자가 새 그림·답변으로 확정한 조건이다. 과거35×12m 스타디움과 별도 시나리오이며 기존 자료·실패·검토 서명을 보존한다.

## 배치

좌하단(남서쪽)을(0,0), +x를동쪽, +y를북쪽으로 둔다.

|항목|값|근거 구분|
|---|---|---|
|경기장 바닥 / 그물 높이|30×5m / 5m|사용자 확정|
|차량 패드 중심 경로|(1,2.5)→(29,2.5)m, 28m직선|사용자 확정 / 중앙 배치 동의|
|드론 초기 위치|(2,2.5−d,1)m|사용자 그림: 출발점보다 동쪽1m앞|
|드론 초기 방향|북쪽에서 동쪽20° = +x기준반시계70°|사용자 확정 / 좌표계 변환D|

## 동작과 입력 경계

호버 준비→차량 출발→고정 시선 대기→영상 ArUco발견→정렬/속도일치→접근→하강→지지 확인/모터종료→3초 유지. 영상 발견 전에는진입자리회전/래스터/트랙으로대기이동을 하지않는다. 발견 후의 시각 추종·정렬 yaw보정은 기존 명령 제한을 유지한다.

호버 준비는 기존 HoverHandoff의PC센서 추정 위치·속도·자세로 판정한다. 준비 이벤트만 plant의차량운동 시작 시각을 초기화한다. 준비되지않으면 출발시키지 않는다. 차량 설정속도·출발시각·거리·참값은 제어기/추정기 공개 설정에 포함하지 않는다. 차량FF는 기존처럼영상/센서의추정속도이고, FB는상대위치·속도오차다. 실제기체의이륙/미션2경로/무선통신은 구현·검증한 것이 아니다.

`.15m/s²`에서`.3m/s`까지2초,각가속/감속거리`.3m`,28m의총주행시간95.333초다(D). 위치·속도가연속인사다리꼴프로파일이며 가속도의jerk연속성/실제차량응답은미검증이다. 실험명령 포화는기존`.4m/s`,`.15m/s²`,yaw`10°/s`,yaw가속`20°/s²`,상승`.10`/하강`.06m/s`; 접촉부하강`.025m/s`. 최대순수수평추격여유는`.4−.3=.1m/s`이고횡방향/높이변화중에는더작아진다(D). 포화는제조사최대성능주장이아니다.

## 실패 시험 종료

사용자가요청한‘못찾은채화각을지나감’은 시험장치가가상카메라·수직판의실제배치를투영해판전체가오른쪽수평화각외부에연속`.25초`있을때`unrecognized_marker_passed_camera_fov`로기록하고닫는다. 수평화각에한번이라도겹친후에만적용한다. `.25초`는명시된가상전송지연`.05초`보다긴S유예이며실기통신보장이아니다. **판정 참값은시험종료/평가전용이고추종제어·인식결과에전달하지않는다.** 해당차량위치·투영을실기에서얻을수있다는주장도하지않는다.

`corners`가있는목표ID디코딩영상을한번이라도처리했으면단순미인식통과종료를적용하지않는다. 이를미터단위위치관측승인으로승격하지않고기존coarse/metric/불확실성/영상소실안전조건을유지한다. 완료된착륙이없는데직선끝에차량이멈추면별도실패종료한다. 정지한차량에대한접촉을이동차량착륙성공으로집계하지않는다.

실제K/D/장착자세/롤링셔터·렌즈왜곡은U/S이므로위화각통과시각도조건부다. native입력은mono8/320×320이며87°공칭화각가정과기존focus계약을유지한다. sensor/동역학/근접ToF미확정항목은기존`hardware-sensor-evidence.md`와프로필을참조한다.

## 프로그램 실행

```bash
bash ./scripts/run_mission3_automation.sh
```

브라우저의 `http://127.0.0.1:8765`에서거리범위·반복횟수·동시실행1~4개·seed·제3자영상옵션을선택하고시작/중지한다. 로컬PC에서만접속한다. 새라이브러리시스템설치·계정·외부서버가필요없다.

화면없이같은실행:

```bash
bash ./scripts/run_mission3_automation.sh --batch --workers 4 --render-video
```

계획만저장할때`--plan-only`,단일거리시험은`--start-distance 1.25 --end-distance 1.25`,반복은`--repeats N`을추가한다. 거리별비교에서같은반복번호의seed는동일하게둔다. 조건16개가모두사전선언된독립시험이며한비행의시간순서를병렬로분할하지않는다. 완료순서는거리순서와다를수있다.

각배치는 `artifacts/mission3/automation/<시각>/`에계획/전체분모/소스·라이브러리·설정SHA/원로그/원본FFV1영상/재생H.264/명령포화감사/픽셀일치검증/그래프/선택한제3자영상/JSON진행표/Markdown보고서를보존한다. 소스변경이검출되면그실행은오류로남는다. 단일작업600초벽시계한계/취소시자기자식processgroup에만SIGINT→최대5초뒤SIGKILL;관련없는프로세스를종료하지않는다. 중단한조건·미시작조건도삭제하지않는다. 다시시작하면새배치를만든다.

자동평가는조건부접촉/네발지지·PWM0·3초/차량속도/직선조건을확인하지만독립검토서명을생성하지않는다. 제조사일치·정식·실기성공수는0이다. 프로그램에는온라인파라미터자동튜닝/하드웨어통신/대회승인기능이없다.
