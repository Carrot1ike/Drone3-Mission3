# 미션3 탐색 시간과 배터리 검증 공백

현재 물리 시험의 전압은 **4.2V 일정이라는 S 가정**이다. 전류 적분·배터리 내부저항·방전·AI-deck/Flow 소비전력·미션1/2에서 소비한 에너지를 재현하지 않는다. 접촉에 성공해도 실제 비행시간 검증을 통과한 것이 아니다. `pm.vbat`를 읽는 실제 logger parser와 배터리 모델도 별개다.

제조사 [Crazyflie2.1 제품 페이지](https://www.bitcraze.io/crazyflie-2-1/)와 [Rev3 데이터시트](https://www.bitcraze.io/documentation/hardware/crazyflie_2_1/crazyflie_2_1-datasheet.pdf)는 기본 배터리 비행시간7분을 공개한다. [FAQ](https://www.bitcraze.io/support/f-a-q/)는 사용 조건에 따라 달라진다고 설명한다. 이는 AI-deck·Flow를 장착한 연속3미션의 남은 비행시간 보장이 아니다. 이 자료를 근거로 임의의 덱 장착 endurance 수치나 실제 SOC를 만들지 않는다. 2026-10-08 읽기 전용 재확인.

사용자가 정한 stadium 길이는 `2×20 + π×7.5 = 63.562m`이고 .25m/s에서 한 바퀴는 **254.248초**다(D). 특정 고정 관측점에서 차량을 놓치면 대기 시간이 길어질 수 있다. 실제 검출 시각·시야 조건에 따라 달라지므로 한 바퀴 안 검출을 보장하지 않는다. 경기장·진입점·트랙 지도로 가까운 관측점을 정하는 현재 정책은 이 탐색 이동을 줄이되 차량 live phase를 입력으로 사용하지 않는다.

동결 지점2 시험 seed271은 약339초의 전체 가상 실행 후 모터 정지 유지까지 끝났으며 실제 접촉은335.54초에 기록됐다. 정확한 종료시각·준비 호버·미션시계는 해당 원본 `adapter-summary.json`에서 확인해야 한다. 이처럼 수분을 쓰는 성공은 미션1/2 소요시간과 부하 조건을 함께 평가해야 한다. 공개7분과 숫자가 작다는 이유만으로 실제 배터리 여유가 있다고 결론 내리지 않는다.

실기 이식 전 필요한 근거는 배정 배터리·덱 revision, 실제 조립 상태의 전압/전류/비행시간, 미션3 인계 당시 남은 에너지, 통신·처리 지연과 안전한 종료 여유다. 현재 장비가 없으므로 U로 남긴다. 이번 시뮬레이션에서 연구 coverage를 늘리기 위해 미션 timeout을 무작정 늘리거나 배터리 한계를 검증했다고 표시하지 않는다.
