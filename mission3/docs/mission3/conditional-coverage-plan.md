# 조건부 연구 모델의 진입 방향 시험 계획

이 계획은 실제 제조사 일치 성공을 승인하지 않는다. `evaluation-contract/1`의 qualified 집계·진입점 승격 조건·평가기 SHA·과거 리뷰는 그대로 유지한다. 제조사 미공개 조립·광학·센서 전달값을 U로 남기면서도, 사용자가 허용한 근거 있는 미확정 가정으로 여러 방향을 시험하기 위한 별도 연구 계획이다.

1. 동일 frozen code/config의 entry1 새 seed43/47/53/59/61에서 전체 sensor→RPYT→physics 미션을 실행한다. 성공·실패 모두 보존하고 처음부터 계획에 넣은 seed만 집계한다.
2. 접촉·PWM0·네 발3초 지지·차량 연속 이동·직선 하강·영상 계약이 통과한 각 실행에 독립 하위 에이전트 검토를 받는다. conditional contact 승인을 제조사 qualified 승인으로 바꾸지 않는다.
3. 이 모델의 entry1 개별 접촉 승인5회 전에는 다른 진입 방향의 연구 검증도 확대하지 않는다. 5회 후 entry2부터8까지 동일하게 진행한다. 새로운 코드는 새 frozen series/사용하지 않은 seed에서 다시 검증한다.
4. 8개 방향 검증 뒤 알려진 임의의 진입점·초기 정면을 갖는 시험을 계획한다. 실제 vehicle phase/speed/yaw는 여전히 추정만 한다. 예정 시간 안에 끝나지 않은 단계는 미완료로 남긴다.

공식 qualified ledger와 연구 coverage 표에는 서로 다른 필드를 사용한다. 연구 진행을 `qualified_mission_success`, 장비 승인, 실기 성공률, 제조사 사양 일치로 표시하지 않는다. source가 다른 역사적 training 성공을 새 시리즈5회에 섞지 않고, 실패가 생기면 실패 원인·수정·새 시험 계획을 남긴다.
