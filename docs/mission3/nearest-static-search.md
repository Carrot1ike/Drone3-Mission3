# 지도 기반의 가까운 관측점 선택

2026-10-08. 실제 트랙 픽셀 인식은 구현하지 않았다. 사용자가 허용한 정적 경기장·트랙 배치와 진입 위치·초기 방향을 사용한다. 차량 위치·속도·진행 방향은 관측 결과로만 추정한다.

## 실패와 수정 근거

`rpyt-handoff-quality-grace-entry2-five-v1`의 미사용 seed 137/139/149/151/157은 모두 같은 고정 소스·설정·라이브러리에서 마커 획득 전 위치 추정 불확실성 제한으로 중단됐다. 지점2(1,18)에서 기존 위쪽 관측점(33,14.1)까지 약32.24m 이동하도록 계획했으며, 약20m 이동 후 조건부 위치 표준편차의 최댓값이1m를 넘었다. 이미지 수용0·접촉0이다. [원 시험 계획](../../artifacts/mission3/frozen-series/rpyt-handoff-quality-grace-entry2-five-v1/plan.json)과 모든 실패 로그를 보존한다.

새 opt-in `search_station_policy=nearest_static`는 진입점 x를 알려진 직선 중앙 범위[17,33]m로 제한해 가까운 관측점으로 향한다. y는 가장 가까운 상·하 직선 바깥35cm, 관측 높이는70cm다. 지점2의 목표는(17,14.1)이며 이동은 약16.47m다. 출발 후15초 고정 시선 대기, 위치 불확실성1m 제한, 영상 판정·착륙 조건은 유지한다. 기본 upstream 정책과 과거 결과를 덮어쓰지 않는다. [별도 실험 설정](../../config/mission3-rpyt-nearest-station-sensitivity.json).

이 거리 계산은 위치와 지도에 대한 정적 유도값이다. 차량이 관측점에 도착할 시각을 알거나 차량을 관측 때 출발시키지 않는다. 17/33m,35cm,70cm는 탐색·가시성 연구를 위한 소프트웨어 설정이며 제조사 하드웨어 사양이 아니다.

## 곡선과 착륙을 구별

가까운 관측점이 해당 진행 방향의 직선 끝에 놓일 수 있다. 이때 마커를 획득하더라도 남은 직선 거리만으로 착륙을 끝낼 수 있다는 가정을 하지 않는다. ACQUIRE·LINEUP·LOWER_ALIGN·APPROACH는 추정 차량 상태를 따라갈 수 있지만 TRACK에서 관측된 직선,1.5초 직선 확인, 신선한 영상, 상대 오차·속도, 착륙과 모터 정지 뒤3초 유지에 필요한 남은 거리를 확인해야 한다. 곡선이면 최종 접근·착륙 전환을 보류한다. 가까운 위치 탐색만으로 곡선 추종이나 임의 방향 착륙이 성공했다는 결론은 내릴 수 없다.

초기 이동은 IMU와 정지 바닥 Flow·ToF의 추정에 의존한다. 상대 영상과 지도 제약을 얻기 전 yaw·gyro 잔여 편향 오차가 거리와 함께 누적된다. 이 불확실성은 측정으로 보정된 확률이 아니며, 가까운 관측점을 고르는 것 자체가 실기체의 위치 정확도를 보장하지 않는다. 현재 지도 anchor의 미확정 상관성을 이유로 위치 공분산을 강제로 줄이지 않는다.

## 검증

가까운 관측점 선택·plant 속도 비사용·잘못된 정책 거부와 기존 탐색·terminal·복구 검사를 합해52개 통과. 지점2의 기존 실패 seed137/139를 재사용한 비교와 지점1 seed107의 회귀 비교를 training으로 기록한다. 재사용한 시험은 새 holdout 성공 수에 포함하지 않는다. 새 소스·설정으로 동결한 별도 미사용 seed 시험과 각 접촉의 독립 검토가 완료되기 전 지점3으로 확대하지 않는다.

현재 비교 실행 결과는 아직 진행 중이며 이 문서에 성공을 선기록하지 않는다.


## 07:32 후속 수정: 직선에서 높이 조절 준비

가까운 관측점 training seed137/139는 모두 마커를 획득하고 곡선을 따라 다음 직선으로 진행했지만, LINEUP에서 곡선 진입 전에70→40cm로 낮춰 장시간 추종하는 동안 free-flight 모터·IMU 보정의45초 유효 시간이 만료됐다. 두 실행 모두 최종 상대 Flow 품질이 부족할 때 보정 IMU 경로를 사용할 수 없어 중단했고 접촉·모터 정지는 없다. seed139는 ACQUIRE95.92s, LOWER_ALIGN102.06s, APPROACH152.52s, 최종중단164.92s다. 실패를 제거하거나45초 유효 시간을 늘리지 않았다.
