# 마지막 신뢰 영상과 수직 추정 품질

2026-10-08. `tof27-straight-preparation-entry1-five-v4`의 5개 미사용 조건은3회 패드 평가 통과·2회 중단이었다. 결과와 실패 분모를 보존하며 제조사 일치 판정은0이다.

## 초점 경계의 새 pose

seed193은 TRACK에서 신뢰 가능한 영상을 확보했으나 최종 접근의 새 IPPE pose가 광학 깊이 .299699m를 추정했다. 이 값이 마지막 이미지 quality를 덮어쓰면서30cm 최소 깊이 gate를 만족하지 못해 IMU 경로로 인계할 수 없었다. 상대 오차·속도·직선·보정 freshness는 만족했다. 접촉·모터 정지는 없다.

새 opt-in `observer.metric_pose_min_depth_m=.32`는 추정 깊이32cm보다 가까운 metric pose를 거부하고 기존 차량 상태와 마지막 신뢰 quality를 유지한다. 그 영상 자체는 원본 기록에 남으며 실제 위치나 차량 상태로 복구하지 않는다. 기존 모터 정지·높이·마커 영상 계약은 그대로다.32cm는 제조사 새로운 사양이 아니라 공개 DOF30cm에20mm 소프트웨어 여유를 더한 S 설정이다.90px 코드에서 두 변의3px 오차는 깊이 약10mm에 대응한다는 단순 유도와 여유를 사용한다. 실제 K/D·흐림·상관 오차의 확률 보장이 아니다.

## 높이 오차와 비교

seed199는 실제 패드에 접촉했지만 추정 body 높이가 보정된 예상 .0145m의 허용 하한 .0025m보다 낮아져 접촉 후보를 끝내지 못했다. 모터 정지 없이6초 예측 만료로 회수했다. 센서로 네 발 접촉을 직접 알 수 없으므로 실제 접촉 로그를 온라인으로 전달하거나 성공으로 강제 승격하지 않는다.

깊이 guard만 적용한 재사용193/199는 모두 패드 접촉·모터 정지·3초 유지 평가를 통과했다. 이는 마지막 영상의 선택이 이후 추정 궤적에 영향을 준 사례이며 수직 오차를 일반적으로 해결했다는 결론은 아니다. 각 실행은 training으로 기록하고 개별 독립 검토한다.

수직 ToF 속도의 회귀 창을 .4→.8초로 늘린 별도199 비교는 초기 호버 준비를15초 안에 끝내지 못해 실패했다. 이상 독립4mm 잡음·40Hz에서 기울기 표준편차는16표본/.4초의8.66mm/s에서32표본/.8초의3.06mm/s로 줄지만, 실제 제어에는 지연이 늘어난다. 이 변경은 현재 방향별 시험에 채택하지 않았다. 실제 ToF 잡음·반사·correlation·sample capture 정보는 미확정이다.

## 검사와 다음 시험

원본 native pixel 영상으로 경계 pose가 앞선 신뢰 관측을 덮지 않는지, 수직 affine 이동·잡음·회귀 지연·중복/invalid range의 계약을 검사했다. 미션 검사149개 통과. `tof27-depthguard-entry1-ten-v5`는 미사용 조건10개를 사전 고정해 같은 코드·설정·라이브러리로 실행한다. 사용자가 요구한 진입점당5회 이상의 독립 승인 접촉을 조건부 연구 진행 기준으로 쓰되, 계획10개와 실패를 모두 보존한다.10/10 성공이나 실제 기체 보장으로 바꾸지 않는다.
