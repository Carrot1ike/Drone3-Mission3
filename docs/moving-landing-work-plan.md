# 이동 표적 추종·하강 구현 계획

2026-10-04. 사용자가 계획 수립과 실행, 하위 에이전트 사용·인터넷 조회를 허용했다.
외부 저장소·게시물·서비스의 변경/업로드는 먼저 사용자 확인을 받는다. 이번 작업은 로컬 코드·시험 결과만 변경한다.

목표는 영상이 실제 제어 명령을 결정하고 그 명령이 다음 관측을 바꾸는 실행 가능한 기준선이다.
카메라는 본래 흑백 320×320이며, 제조사 기본 하드웨어·장착 조건을 유지한다.
모델의 미공개 관성·장착 수치로 막히는 기체 물리 시험과, 진행 가능한 관측·상위 제어·ROS 시험을 분리한다.

| 작업 | 담당 | 완료 증거 |
| --- | --- | --- |
| 영상→카메라 광학점 상대 위치/yaw 관측·시간 필터 | 메인 | 실제 렌더 영상의 관측 로그, 참값을 넣지 않은 제어 입력 |
| 정렬→접근→추종→하강 상태기계·FF+피드백·손실 처리 | Gibbs | 순수 제어 모듈, 상태 전이·제한·손실 시험 |
| 렌더→관측→명령→운동 순환, 영상/CSV/비교 평가 | 메인 | FF 활성/비활성 및 영상 누락 실험, 성공/실패 모두 저장 |
| 동일 제어기의 ROS 영상·명령 순환 | 메인 | 공유 CPX/ROS 영상 수신, ROS 속도 명령을 소비하는 가상 광학점 |
| 이동 표면 상대속도·ToF 바닥/상판 전환 | Sagan | 이상적 센서 광선/각속도 벤치, 단위·표면·출처 로그 |
| 최종 설명·재현 명령·검증 제한 | 메인 | 실행 스크립트, 편집 가능한 제어도, 결과 그림/영상 |

단계별 기준은 실행 전 기록한다. 제공 기체의 물리 성능이나 대회 합격 기준으로 사용하지 않는다.
카메라 중심 운동학 COMPLETE는 지정 높이에서 추종·하강 조건을 만족했다는 뜻이며 접촉 착륙 성공이 아니다.
FF 속도 0.3m/s는 이 시험의 차량 설정값이다. 영상에서 추정한 차량 속도로 표시하지 않는다.
실제 기체 명령 adapter에는 확인된 카메라 보정·표준 장착 변환과 명령 좌표 의미가 필요하다.
