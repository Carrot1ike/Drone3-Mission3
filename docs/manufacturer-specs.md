# 제조사 사양 검증

확인일: **2026-09-30 (Asia/Seoul)**. 아래 모든 공식 URL을 이 날짜에 확인했다.

2026-10-04 갱신: 사용자가 제공 카메라의 **흑백 320 × 320**을 고정 조건으로 재확인했다.
이는 선택 가능한 변환·해상도 옵션이 아니다. 공유 SIL 모델의 324 × 244/70°와 제3자 동역학 값은
제공 기체 사양으로 채택하지 않는다. 적용 코드·검증 범위는 [제공 기체 적용 기준](provided-hardware-enforcement.md)을 따른다.
공식 단색 카메라 모듈 PDF는 2026-10-04에도 다시 확인했다.

## 적용 정책과 대상

- **제조사 사양만 사용한다는 것은 사용자 요구에 따른 본 과제 정책**이다. Bitcraze의 공식 데이터시트·제품 문서와 공식 저장소를 근거로 삼으며, 논문·판매대행사·제3자 시뮬레이터의 수치로 누락값을 채우지 않는다. 공식 문서에서 외부 논문을 링크해도 그 수치가 제조사 측정 사양이 되는 것은 아니다.
- 대상은 **표준 Crazyflie 2.1 + AI-deck + Flow deck**이다. Crazyflie 2.0, 2.1+, Brushless, 추력 업그레이드 키트의 사양을 대입하지 않는다.
- **실물 AI-deck가 1.1인지, Flow deck이 v2인지는 미확정**이다. 아래 덱 사양은 해당 제품 버전일 때만 적용한다. 데이터시트의 문서 개정 번호와 실물 하드웨어 개정 번호도 구분한다.
- 사용자는 실기체·Crazyradio가 없으며 시뮬레이션 승인 후 장비를 지급받을 예정이다. 소프트웨어 변경은 허용되는 것으로 이해하고 하드웨어 개조는 금지한다. 제조사 장착 안내 검토는 [mounting-review.md](mounting-review.md), 기체 동역학 없는 관측 시험은 [visibility-experiment.md](visibility-experiment.md)에 기록했다.
- 기체 개조 금지, AI-deck 기본 장착 유지, PC 영상 인식·외부 제어는 사용자 조건이다. 차량은 0.3 m/s 등속 직진하며, 앞쪽 수직 깃발의 ArUco 면은 뒤쪽 30 × 30 cm 착륙장을 향한다. 이는 제조사 사양이 아니다. 마커 자체 크기·높이·착륙점까지의 변환은 미확정이다.

기존 [제품 주소](https://www.bitcraze.io/products/crazyflie-2-1/)는 확인 당시 [2019년 재입고 블로그](https://www.bitcraze.io/2019/07/crazyflie-2-1-back-in-stock/)로 리다이렉트됐다. 표준 2.1의 근거는 **과거 공식 제품 페이지 [S2]와 보존된 공식 데이터시트 [S1]**로 확정했다. 과거 제품 페이지는 2.1이 단종되고 2.1+로 대체되었다고 명시하므로 후속 제품과 혼동하지 않는다.

## 공식 펌웨어 상수와 시뮬레이터의 취급

공식 펌웨어는 확인일의 커밋 **`e2fdc21159d40d2053fbfc92d14374996ffd2bd3`**로 출처를 고정했다 [S7–S8].

- `platform_defaults_cf2.h`의 `ARM_LENGTH = 0.046 m`, 기본 `CF_MASS = 0.029 kg`은 **제어 구현의 기본 상수**다. 질량 재정의·업그레이드 분기가 있고 덱 포함 실기체 측정 결과를 뜻하지 않는다. 로컬 CrazySim의 `CF_MASS = 0.027 kg` 역시 표준 2.1의 공식 이륙 질량 29 g을 대체하지 않는다.
- 같은 공식 파일에는 **legacy 프로펠러용 전압→추력 3차 근사 계수**가 공개되어 있다. 따라서 추력 관련 공식 자료가 전혀 없다고 결론내리지 않는다. 다만 계수·`THRUST_MAX`·`THRUST2TORQUE`는 보상·제어용 모델 값이며, 제조사 측정 사양·성능 보증과 구분한다 [S7, S9].
- `Kconfig`는 legacy, 2.1+ 프로펠러, 추력 업그레이드 키트를 별도로 선택하며 확인 커밋의 기본 선택은 **2.1+**다. 공통 `cf2` 이름만으로 표준 2.1과 동일한 추진 구성을 보장하지 않는다 [S8]. 이 검증에서는 빌드 설정이나 실기체 펌웨어를 변경하지 않았다.
- 기존 **`cf2x_T350`·`cf2x_L250`는 모두 제조사 검증 모델로 인정하지 않는다.** 로컬 모델에 질량·관성·추력·카메라 설정이 있거나 공식 저장소에 포함되어 있어도, 각 값의 제조사 측정 출처와 표준 2.1·덱 구성의 일치가 확인되어야 한다. 이름의 유사성이나 시뮬레이션 실행 성공은 이 검증을 대신하지 않는다.

## 미확정 항목

| 항목 | 확인 결과 및 채택 정책 |
| --- | --- |
| 실물 버전·조립체 | AI-deck 1.1/Flow v2 여부, 각 하드웨어 개정, 전체 질량·무게중심·덱 장착 후 외곽 치수는 미확정. 문서의 개정 표를 실물 확인으로 간주하지 않는다. |
| 관성·공력·모터 동특성 | 검토한 공식 제품 사양에서 **표준 2.1 + 해당 덱 조립체의 제조사 측정 관성 텐서**를 확보하지 못했다. 공력 계수·장착 구성에 맞는 모터 응답값도 미확정이며 제3자 수치를 대입하지 않는다. |
| 적용 가능한 추력곡선 | Bitcraze의 2021년 2.1 시험과 펌웨어 근사는 공개되어 있다 [S7, S9–S10]. 그러나 실제 기본 모터·프로펠러·배터리·펌웨어 조건과의 일치, 오차 범위, 본 구성의 PWM→추력 적용은 미확정이다. 공식 문서의 2015년 과거 시험표나 외부 논문을 표준 2.1의 확정 곡선으로 사용하지 않는다. |
| 카메라 내부·외부 파라미터 | 실제 영상 모드의 `fx, fy, cx, cy`, 왜곡 계수, 카메라→기체 변환과 장착 피치·위치는 미확정. 공칭 FOV나 제품 사진으로 보정값을 만들어 채택하지 않는다. 기본 장착을 유지하며 하향 카메라로 가정하지 않는다. |
| 실제 영상·착륙 관측 | PC 스트림 해상도·fps·촬영 시각·전송 지연, 깃발의 최종 하강 중 가시성, 근거리 ArUco 검출 성능은 미확정. 제조사 센서 프레임률·피사계 심도만으로 성공을 보장하지 않는다. |

미확정값은 빈 항목으로 유지한다. 추후 실물 확인·캘리브레이션 결과를 얻더라도 **사용자 기체 측정값**으로 별도 표기하며 제조사 사양으로 바꾸어 적지 않는다.
