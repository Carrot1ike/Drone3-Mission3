# 미션2 — run22 인지·판단·비행 자료

현재 공유 기준은 **미션2 run22**입니다. 전방 영상과 영상에 연결된 기체 추정 상태를 사용해 링·블록·벽·출구를 통과한 SITL 실행의 코드와 근거를 정리했습니다. 삼각측량을 사용하지 않습니다.

**결과:** 230.913초, 8/8 순서 통과, 비바닥 접촉 표본 0, 호스트 DONE. 별도 연착지 평가는 실패했습니다. 단일 SITL 개발 실행이며 일반적인 성공률이나 실기체 검증을 뜻하지 않습니다.

run22는 입구 폭1.5m·출구 폭1.8m, 링 규격과 출구 폭 사전값, 기존 ringPass v2 수정 펌웨어를 사용했습니다. 벽 앞 좌우45° 스캔을 약17~18초로 줄였고 통과 여유는20cm입니다. 이후 요청한 출구1.5m와 전진 관측·회전 확인 정책은 이 결과에 섞지 않습니다.
